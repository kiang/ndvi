返回 NDVI 報告

專案技術說明

本專案透過 NASA MODIS 衛星影像，自動化分析台灣 22 個縣市在 2016 至 2025 年間的植被覆蓋變化趨勢，並以互動式網頁呈現分析結果。

問題背景

需要解答的問題

台灣各縣市近十年的樹木覆蓋率（植被覆蓋）是增加還是減少？變化幅度有多大？哪些縣市的植被退化最為嚴重？

為什麼用 NDVI

NDVI（常態化差值植生指標）是衡量植被健康與密度的標準遙測指標。數值範圍 0 到 1，越高代表植被越茂密。透過長期追蹤 NDVI 變化，可客觀量化植被增減趨勢。

資料來源

項目規格
衛星產品NASA MODIS MOD13Q1 v061（Terra 衛星）
空間解析度250 公尺
時間解析度16 天合成影像
NDVI 計算產品已預先計算 NDVI，並附帶品質旗標，無需從原始波段計算
涵蓋圖磚h28v06、h29v06（完整覆蓋台灣本島及離島）
時間範圍2016 年 1 月至 2025 年 12 月（約 460 筆影像）
資料格式HDF4（NASA EOS-HDF）
資料取得NASA LP DAAC，透過 CMR API 搜尋、HTTPS 下載
行政區界內政部 22 縣市行政區界 GeoJSON（2020 年 8 月版本）

選擇 MODIS MOD13Q1 而非 Sentinel-2 或 Landsat 的原因：MOD13Q1 提供預先計算且經品質過濾的 NDVI 數值，250 公尺解析度在縣市層級分析已足夠，且自 2000 年起即有連續觀測記錄，是長期植被變遷研究的首選資料源。

系統架構

整個系統由三支 Python 腳本組成一條自動化資料處理管線，最終產出靜態 HTML 網站。無需後端伺服器，所有計算在本機完成。

處理管線詳解

1
衛星影像下載
scripts/download_modis.py
透過 NASA CMR（Common Metadata Repository）API，以台灣經緯度範圍（119°E–123°E, 21°N–26°N）搜尋所有涵蓋台灣的 MOD13Q1 衛星影像條目。搜尋結果經過篩選，僅保留 h28v06 與 h29v06 兩個 MODIS 圖磚。接著以 NASA Earthdata Bearer Token 認證，透過 HTTPS 從 LP DAAC 雲端逐一下載 HDF4 檔案。下載支援斷點續傳（已存在的檔案自動跳過），並驗證下載完整性。每年約 46 筆合成影像，十年共約 460 筆。
2
分區統計計算
scripts/compute_ndvi_stats.py
對每一筆 16 天合成影像執行以下處理：

2a. 子資料集擷取 — 從 HDF4 檔案中擷取 250m 16 days NDVI 子資料集，同時擷取 250m 16 days pixel reliability 品質旗標。

2b. 品質過濾 — 僅保留品質旗標為 0（良好）或 1（尚可）的像素。被雲覆蓋、水體、積雪等低品質像素標記為無效值。

2c. 座標重投影 — 將 MODIS 正弦投影（Sinusoidal）重投影至 EPSG:4326（WGS84 經緯度座標），以便與行政區界 GeoJSON 疊合。使用最近鄰插值法保持 NDVI 值不失真。

2d. 圖磚鑲嵌 — 將同一日期的 h28v06 與 h29v06 兩塊圖磚合併為一張完整的台灣範圍影像。

2e. 分區統計 — 對每個縣市的行政區界多邊形，裁切鑲嵌後的 NDVI 影像，計算有效像素的平均值。NDVI 原始值除以 10,000 轉換為 0–1 範圍。

2f. 年均值彙整 — 將每個縣市全年所有合成影像的 NDVI 平均值彙整為該年度的代表值，輸出至 county_ndvi.json。

3
靜態網站產生
scripts/generate_site.py
讀取計算結果 JSON 與縣市行政區界 GeoJSON，精簡多邊形屬性後輸出至 docs/data/ 目錄。前端頁面 docs/index.html 在瀏覽器端載入這些資料，以 Leaflet 渲染互動地圖、以 Chart.js 繪製趨勢圖表。整個網站為純靜態檔案，無需後端伺服器。

輸出資料格式

核心輸出檔案為 data/county_ndvi.json，結構如下：

{
  "metadata": {
    "product": "MOD13Q1 v061",
    "resolution": "250m",
    "aggregation": "yearly mean",
    "date_range": "2016-2025"
  },
  "counties": [
    {
      "code": "63000",
      "name": "臺北市",
      "name_en": "Taipei City",
      "ndvi_yearly": {
        "2016": 0.6191,
        "2017": 0.6048,
        ...
        "2025": 0.5936
      }
    },
    ...
  ]
}

互動式報告功能

前端報告頁面提供三個主要互動區塊：

NDVI 色階地圖
以 Leaflet 渲染台灣地圖，各縣市依最新年度 NDVI 值填色。色階從暖褐色（低植被）漸變至深綠（高植被），點擊可查看個別縣市詳情。
縣市排序總覽表
列出 22 個縣市的最新 NDVI、起始 NDVI 與十年變化幅度。欄位可排序，變化值以紅綠色標示增減方向。
趨勢折線圖
選取縣市後，以 Chart.js 繪製該縣市 2016–2025 年的 NDVI 年均值折線，同時疊加全國平均線作為參照。含互動式提示框。
統計摘要磚
顯示選取縣市的最新 NDVI 數值、十年絕對變化量（含百分比）、以及全國平均值，快速掌握該縣市的植被狀態。

執行方式

步驟一：下載衛星影像
EARTHDATA_TOKEN="your_token" python3 scripts/download_modis.py

需要 NASA Earthdata 帳號的 JWT Token。下載約 460 個 HDF4 檔案，約需 50GB 磁碟空間。

步驟二：計算分區統計
python3 scripts/compute_ndvi_stats.py

處理所有下載的 HDF4 檔案，輸出 data/county_ndvi.json。視硬體效能約需 30–60 分鐘。

步驟三：產生靜態網站
python3 scripts/generate_site.py

將計算結果複製至 docs/data/，靜態網站即可透過任何網頁伺服器提供服務。

方法學限制

MODIS MOD13Q1 的 250 公尺解析度適合縣市層級的整體趨勢分析，但無法辨識個別街廓或小型綠地的變化。16 天合成影像已儘可能排除雲覆蓋影響，但台灣多雨的氣候仍可能造成部分時段的有效觀測數量較少。NDVI 反映的是整體植被覆蓋密度，無法區分自然林地、農田、與人工綠化的差異。年均值平滑了季節性波動，適合追蹤長期趨勢，但可能遮蔽特定季節的劇烈變化。
