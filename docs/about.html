返回 NDVI 報告

專案技術說明

本專案透過 NASA MODIS 衛星影像，自動化分析台灣 22 個縣市在 2016 至 2025 年間的植被覆蓋變化趨勢，並以互動式網頁呈現分析結果。

問題背景

需要解答的問題

台灣各縣市近十年的樹木覆蓋率（植被覆蓋）是增加還是減少？變化幅度有多大？哪些縣市的植被退化最為嚴重？

為什麼用 NDVI

NDVI（常態化差值植生指標）是衡量植被健康與密度的標準遙測指標。數值範圍 0 到 1，越高代表植被越茂密。透過長期追蹤 NDVI 變化，可客觀量化植被增減趨勢。

資料來源

項目規格
衛星產品NASA MODIS MOD13Q1 v061（Terra 衛星）
空間解析度250 公尺
時間解析度16 天合成影像
NDVI 計算產品已預先計算 NDVI，並附帶品質旗標，無需從原始波段計算
涵蓋圖磚h28v06、h29v06（完整覆蓋台灣本島及離島）
時間範圍2016 年 1 月至今（自動涵蓋最新可用資料，目前至 2026 年）
原始格式HDF4（NASA EOS-HDF），下載後轉換為壓縮 GeoTIFF
資料取得NASA LP DAAC，透過 CMR API 搜尋、HTTPS 下載
行政區界內政部 22 縣市行政區界 GeoJSON（2020 年 8 月版本）

選擇 MODIS MOD13Q1 而非 Sentinel-2 或 Landsat 的原因：MOD13Q1 提供預先計算且經品質過濾的 NDVI 數值，250 公尺解析度在縣市層級分析已足夠，且自 2000 年起即有連續觀測記錄，是長期植被變遷研究的首選資料源。

系統架構

整個系統由四支 Python 腳本組成一條自動化資料處理管線，最終產出靜態 HTML 網站。無需後端伺服器，所有計算在本機完成。

處理管線詳解

1
衛星影像下載
scripts/download_modis.py
透過 NASA CMR（Common Metadata Repository）API，以台灣經緯度範圍（119°E–123°E, 21°N–26°N）搜尋所有涵蓋台灣的 MOD13Q1 衛星影像。日期範圍從 2016 年至當日，自動涵蓋最新可用資料。搜尋結果經過篩選，僅保留 h28v06 與 h29v06 兩個 MODIS 圖磚。以 NASA Earthdata Bearer Token 認證下載 HDF4 檔案，支援斷點續傳與自動重試。
2
GeoTIFF 轉換
scripts/extract_ndvi_tiff.py
從 HDF4 檔案中擷取 NDVI 與品質旗標子資料集，執行以下處理後輸出為壓縮 GeoTIFF，並刪除原始 HDF 檔案以節省磁碟空間（約 80% 大小縮減）：

品質過濾 — 僅保留品質旗標為 0（良好）或 1（尚可）的像素，雲覆蓋、水體等低品質像素標記為無效值。

座標重投影 — 將 MODIS 正弦投影重投影至 EPSG:4326（WGS84 經緯度座標）。

圖磚鑲嵌 — 將同一日期的 h28v06 與 h29v06 合併為一張完整台灣範圍影像。

壓縮輸出 — 以 Deflate 壓縮儲存為 data/tiff/YYYY-MM-DD.tif，每筆約 15–37MB。

3
分區統計計算
scripts/compute_ndvi_stats.py
讀取 GeoTIFF 檔案，對每個縣市的行政區界多邊形裁切影像，計算有效像素的平均 NDVI（原始值除以 10,000 轉換為 0–1 範圍）。輸出每筆合成影像的逐日 NDVI 值，同時彙整為年均值與估計綠覆蓋面積（NDVI × 縣市面積）。支援增量執行，已處理的日期自動跳過。
4
靜態網站產生
scripts/generate_site.py
讀取計算結果 JSON 與縣市行政區界 GeoJSON，精簡多邊形屬性後輸出至 docs/data/ 目錄。前端頁面在瀏覽器端載入這些資料，以 Leaflet 渲染互動地圖、以 Chart.js 繪製逐日趨勢圖表。整個網站為純靜態檔案，無需後端伺服器。

    "date_range": "2016-2026"

}

互動式報告功能

前端報告頁面提供三個主要互動區塊：

NDVI 色階地圖
以 Leaflet 渲染台灣地圖，各縣市依最新年度 NDVI 值填色。色階從暖褐色（低植被）漸變至深綠（高植被），點擊可查看個別縣市詳情。
縣市排序總覽表
列出 22 個縣市的最新 NDVI、起始 NDVI 與十年變化幅度。欄位可排序，變化值以紅綠色標示增減方向。
逐日趨勢圖
選取縣市後，以 Chart.js 繪製每筆 16 天合成影像的 NDVI 折線（約 247 個資料點），可觀察季節性植被波動與長期趨勢，同時疊加全國平均線。
統計摘要磚
顯示選取縣市的估計綠覆蓋面積（公頃）、覆蓋面積變化、最新 NDVI 與 NDVI 變化，快速掌握植被狀態。

執行方式

步驟一：下載衛星影像
python3 scripts/download_modis.py

需要 NASA Earthdata JWT Token（存放於 .earthdata_token 或設定 EARTHDATA_TOKEN 環境變數）。自動下載至最新可用資料，已存在的檔案會跳過。

步驟二：轉換為 GeoTIFF
python3 scripts/extract_ndvi_tiff.py

從 HDF4 擷取 NDVI 波段，重投影、鑲嵌、品質過濾後輸出壓縮 GeoTIFF。完成後自動刪除 HDF 原始檔（約 80% 空間節省）。

步驟三：計算分區統計
python3 scripts/compute_ndvi_stats.py

從 GeoTIFF 計算每筆合成影像的各縣市 NDVI，輸出 data/county_ndvi.json。支援增量執行，已處理的日期自動跳過。

步驟四：產生靜態網站
python3 scripts/generate_site.py

將計算結果複製至 docs/data/，靜態網站即可透過任何網頁伺服器提供服務。

方法學限制

MODIS MOD13Q1 的 250 公尺解析度適合縣市層級的整體趨勢分析，但無法辨識個別街廓或小型綠地的變化。16 天合成影像已儘可能排除雲覆蓋影響，但台灣多雨的氣候仍可能造成部分時段的有效觀測數量較少。NDVI 反映的是整體植被覆蓋密度，無法區分自然林地、農田、與人工綠化的差異。估計綠覆蓋面積（NDVI × 縣市面積）為概略估算，並非精確的土地覆蓋分類結果。GeoTIFF 中繼格式保留完整柵格資料，但一旦刪除 HDF 原始檔後，將無法擷取 EVI、反射率等其他波段資訊。
